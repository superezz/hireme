# ViewMe Roadmap

This document outlines the high-level roadmap for ViewMe. Note that features and priorities are subject to change based on community feedback.

## Now (Immediate Priorities)
- **Automated Testing**: Introduce Jest or Vitest to test frontend components and backend routes.
- **Accessibility Improvements**: Ensure the UI meets WCAG standards for contrast and keyboard navigation.
- **License**: Finalize and publish an open-source license.

## Next (Upcoming Features)
- **More Resume Templates**: Expand the available templates for users to choose from.
- **Export to PDF Improvements**: Improve rendering quality of downloaded resumes.
- **AI Improvements**: Allow iterative feedback to Gemini AI (e.g. "make it sound more professional").
- **OAuth Authentication**: Add support for Google/GitHub sign-in.

## Later (Future Vision)
- **Analytics**: Basic tracking of how often a public resume link is viewed.
- **Custom Domains**: Allow users to host their public resume on a custom domain.
- **Performance Optimizations**: Server-side rendering (SSR) or static generation for public resumes.
- **Contributor Tooling**: Add commit linting and better local developer tooling.
