# Security Policy

## Supported Versions

Currently, only the `main` branch (latest release) is actively supported with security updates.

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in ViewMe, **please do not report it by creating a public GitHub issue**.

Instead, please report security vulnerabilities directly to the maintainers:
*(Maintainer to configure: Add your security contact email or instructions on using GitHub's Private Vulnerability Reporting here.)*

**What to include in your report:**
- A descriptive title
- Steps to reproduce the issue
- Expected versus actual behavior
- Any potential impact on user data or infrastructure

**What not to include:**
- Do not disclose the vulnerability in public forums or issues until it has been patched.
- Do not include real passwords, API keys, database credentials, or other production secrets in your report.

## Maintainer Responsibilities

Maintainers will:
- Acknowledge receipt of your vulnerability report quickly.
- Investigate the issue and confirm its validity.
- Develop a patch and test it securely.
- Notify the reporter when the fix is deployed.
